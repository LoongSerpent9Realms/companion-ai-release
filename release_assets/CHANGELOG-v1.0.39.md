# 智能伙伴 v1.0.39

本次发布提供新的 Windows 安装包，面向 AI 陪伴桌宠、本地控制台、Live2D/3D 查看器和本地优先学习能力做了整合更新。

## 主要更新

### 安装与启动体验

- 更新 Windows 安装包，版本号同步为 `1.0.39`。
- 安装后提供桌宠、本地控制台和停止服务等常用启动入口，便于日常使用和退出后台服务。
- 继续支持开始菜单与桌面快捷方式，降低首次安装后的查找成本。
- 安装包继续采用本地优先部署方式，默认服务运行在用户电脑上。

### AI 陪伴与本地学习

- 保留长期记忆能力，可记录用户偏好、重要信息和陪伴习惯。
- 保留教学实验室入口，支持从问答样本、情绪反馈、网页学习、电脑操作示范和陪伴习惯等路线逐步训练。
- 支持训练样本管理，可查看、沉淀和删除本地训练样本。
- 支持行为规则系统，可把固定触发词和处理方式写成本地规则。
- 支持神经网络训练与模型导出相关入口，方便后续继续扩展本地模型能力。

### 现实上下文与多模态能力

- 支持本机时间、前台窗口和最近视觉观察等现实上下文注入，让对话更贴近当前使用场景。
- 支持用户主动触发屏幕观察和摄像头观察，默认不自动采集。
- 支持本地 OCR、图片信息读取、文本/代码/Markdown/HTML 片段读取，以及 CSV/TSV/JSON 等数据文件预览。
- 支持实时天气查询，天气数据来自公开天气接口。

### 桌宠、Live2D 与 3D 查看

- 继续提供桌面宠物窗口，支持置顶、拖动和桌宠模式启动。
- 保留 Live2D 查看器入口，方便查看和调试角色展示效果。
- 保留 3D 查看相关页面，为后续角色展示和模型交互能力留出扩展空间。

### 官网与局域网访问

- 保留本地官网页面和本地控制台入口。
- 支持 LAN 启动模式，同 Wi-Fi 设备可在显式开启后访问本地节点。
- 默认仍只监听本机地址，避免无意暴露到局域网。

### 隐私与运行边界

- 聊天历史、记忆、训练样本、文件索引和观察记录默认保存在用户本机。
- 屏幕观察、摄像头观察和闲置探索仍以用户触发和本地只读为主。
- 不包含绕过登录、付费墙、权限控制、验证码或网站反爬限制的能力。

### 安装包体积与运行时

- 延续安装包体积控制策略，排除可选大型 ML/数据运行时。
- 组件运行环境按需创建，减少安装包内不必要的大型依赖。
- 本次安装包大小约 200.9 MB。
