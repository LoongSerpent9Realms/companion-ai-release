# 智能伙伴 v1.0.49

本次发布提供新的 Windows 安装包，继续围绕本地优先的 AI 陪伴桌宠、个人成长助手、本地控制台和自动更新体验做整理发布。

## 主要更新

### Windows 安装包

- 发布新的 Windows 安装器：`CompanionAI-Setup-v1.0.49.exe`。
- 安装器文件名使用 ASCII 命名，便于 GitHub Release、浏览器下载、镜像服务和命令行脚本处理。
- 安装包内继续包含本地控制台、桌宠启动入口、停止服务入口、图标资源和运行所需的核心文件。
- 保留开始菜单和桌面快捷方式，安装后可直接启动本地 AI 服务或桌面宠物。
- 继续按需创建组件运行环境，避免把可选大型依赖全部塞进安装包。

### 本地控制台与陪伴能力

- 继续提供本地 Web 控制台，用于聊天、训练、查看记忆、管理样本和使用工具能力。
- 保留长期记忆、用户偏好沉淀、训练样本、情绪反馈和行为规则系统。
- 保留教学实验室路线，可从问答样本、情绪反馈、网页学习、电脑操作示范、观察世界和陪伴习惯逐步培养。
- 支持神经网络训练、模型导出和本地成长状态查看，便于后续继续积累个人数据和能力。

### 现实上下文与多模态输入

- 保留本机时间、前台窗口和最近视觉观察摘要等现实上下文能力。
- 支持用户主动触发屏幕观察和摄像头观察；默认不会自动采集屏幕或摄像头。
- 支持图片预览、图片尺寸/格式读取、本地 OCR、文本/代码/Markdown/HTML 片段读取。
- 支持 CSV、TSV、JSON 等数据文件的基础预览和摘要。
- 保留实时天气查询、本地文件摘要和网页读取能力。

### 桌宠、Live2D 与展示页面

- 继续提供桌面宠物窗口，支持置顶、拖动和桌宠模式启动。
- 保留内置 2D 角色区域，并可根据训练与成长状态扩展动作展示。
- 保留 Live2D 查看器入口，方便导入和预览 `.model3.json` 角色模型。
- 保留 3D 查看页面，为角色展示、模型预览和后续交互能力留出扩展空间。

### 更新检测与发布仓库

- 应用内更新信息继续指向官方发布仓库：`LoongSerpent9Realms/companion-ai-release`。
- 更新清单优先从 GitHub Release 读取，安装包资产会从 Release 附件中解析。
- 本次 Release 附带独立更新日志文件，方便用户下载后离线查看版本变化。

### 隐私、安全与访问边界

- 聊天历史、长期记忆、训练样本、上传文件摘要、OCR 结果、屏幕观察记录和本地模型数据默认保存在用户设备上。
- 默认服务只监听本机地址；局域网访问需要显式启用。
- 屏幕观察、摄像头观察和闲置探索保持用户触发或本地只读原则。
- 不包含绕过登录、付费墙、权限控制、验证码或网站反爬限制的能力。

### 安装包体积与运行时

- 延续安装包体积控制策略，排除可选大型 ML/数据运行时。
- 可选能力如 OCR、TTS、远程大模型、PyTorch 训练和插件系统按需要额外启用。
- 本次 Windows 安装包大小约 201.2 MB。

## 已知限制

- Windows 安装包未进行代码签名，SmartScreen 可能显示安全提醒，可在确认来源后选择继续运行。
- OCR、摄像头、TTS、神经网络训练和远程大模型等能力可能需要额外依赖或本机权限。
- 首次启动时如果需要创建组件运行环境，启动时间可能比后续启动更长。
- 局域网访问只建议在可信网络中开启。
