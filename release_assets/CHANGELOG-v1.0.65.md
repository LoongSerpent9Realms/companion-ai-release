# 智能伙伴 v1.0.65

## 本地小模型自成长

- 新增证据门控成长闭环：只有人工批准、工具成功或本地规则验证的经验才可训练。
- 新增“真实样本标定”入口；应用不会自动把聊天记录当作训练真值。
- 候选 TinyLLM 采用稳定训练/留出划分、核心经验回放和固定能力评测；评测不通过不会替换当前模型。
- 支持关键词、正则、完全一致、最大字数和人工确认五种固定评测规则，并可在设置中维护。
- 后台训练显示准备、训练、留出评测、固定评测、激活等阶段；取消训练会阻止候选激活。
- 支持查看版本、恢复通过评测的历史模型、审核/停用/删除经验，以及导出不含敏感内容的本地诊断包。

## 本地图片反馈与 ComfyUI

- 生成的本地图片配方可标注采用、太亮、太暗、简单些或拒绝，供后续本机配方复用。
- 新增可选 ComfyUI 本机桥接：使用用户提供的 API Format workflow、提示词节点与可选种子节点。
- ComfyUI 不可用或生成失败时自动回退到内置心情卡片；默认不启用，不连接公网。

## 验证

- 已通过成长闭环、后台任务、图片反馈、运行时、审计和 TinyLLM 运行时的自动化回归测试。
