# 智能伙伴 v1.0.36

本次发布提供新的 Windows 安装包。

## 更新内容

- 优化 AI 陪伴桌宠安装包与启动入口，安装后可从桌面或开始菜单启动桌宠、本地控制台和停止服务。
- 增强本地 AI 学习能力，包含长期记忆、教学实验室、行为规则、训练样本、神经网络训练和模型导出等入口。
- 增加屏幕观察、摄像头观察、OCR、文件读取、天气、本机时间和现实上下文能力，默认仍保持本地优先与用户触发。
- 完善 Live2D/3D 查看器、本地官网页面和局域网启动支持，方便从官网或同 Wi-Fi 设备访问本地节点。
- 改进安装包体积控制，排除可选大型 ML/数据运行时，首次启动时按需创建组件运行环境。
